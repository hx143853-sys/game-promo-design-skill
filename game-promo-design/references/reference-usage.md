# 参考图使用边界与缺失素材规划

## 一、先分清“自有资产、参考借法、创作空间”三道边界

用户的输入图片承担完全不同的法律与设计职责。动手前必须逐张核对，**严禁把“学风格或学版式”演变成“顺手挪用参考图里的具体物件”**。

| 输入类型 | 允许提取/复用的内容 | 绝对禁止的行为（红线） |
|---|---|---|
| **1. 自有角色设定／立绘** | 角色面部特征、发型发色、体型、服装剪裁、主配色、标志性武器与专属配饰 | 机械照搬直立站桩姿势（除非用户要求原图排版）；把同一角色多视图当成多个人；擅自混合不同皮肤版本 |
| **2. 海报／版式／构图参考** | 画面分区比例、阅读动线、主次面积比、镜头仰俯角、明暗大关系、图文留白节奏 | **禁止移植参考图中的角色、具体道具、建筑形制、专属符号、图标、印章、边花或原文案** |
| **3. 画风／色彩／光影参考** | 绘画媒介（如赛璐璐/半厚涂/水墨/PBR）、描线粗细、明暗上色方式、材质高光规律、主辅色温比例 | 把“画风参考”当成“内容参考”；**禁止通过改色、微调或重画，把风格参考里的具体物件或背景照搬过来当原创** |
| **4. 艺术字／字组参考** | 字面高宽比、笔画起收笔逻辑、字组大小错落结构、主副字咬合方式、表面材质工艺 | 照抄参考图中的文字内容或品牌名；把参考字旁边的专属 IP 图形/徽章原样搬用 |
| **5. 自有官方 Logo／指定图标** | 品牌准确图形、标准比例、官方配色与安全距离 | 让生图模型自由重绘变形；压扁拉长；擅自添加未授权的副标或符号 |
| **6. 自有场景／实机画面** | 本项目真实的建筑、生态、UI 框架与已证实的玩法事实 | 将低清局部脑补成不存在的官方系统；用生成的假 UI 冒充实机截图 |
| **7. 用户草图／修改标注** | 用户明确指定的模块位置、构图走向或局部修改范围 | 无视用户的最新草图坐标，退回通用套路构图 |

> **核心铁律**：只有用户明确指定为“我方角色/我方道具/我方Logo/可用素材”的图片，才能复用其具体形象。对于仅用于参考风格、构图或氛围的图片，**哪怕把里面的宝箱、法阵、建筑、花边、图标换个颜色或重画一遍，也属于违规挪用参考对象**。

## 二、缺失素材的提前规划机制（Missing Asset Planning）

当画面需要某些元素（如主标题艺术字组、章节分隔装饰、主题背景环境、承托底板、活动通用奖励道具），但用户只提供了角色立绘和外部风格参考时，**必须提前规划缺失素材，绝不能去参考图里“抠”或“抄”**。

在制定方案和编写提示词前，按以下四项列出缺失素材规划：

| 规划项 | 必须明确回答的问题 | 正确示范（以冷峻机能风角色长图为例） | 错误做法（违规） |
|---|---|---|---|
| **1. 是什么（素材定义）** | 画面缺少哪几件具体视觉元素？哪些做独立透明槽，哪些在整图背景中一并绘出？ | 需新建：① 独立透明主艺术字组；② 章节标题斜切底条；③ 贯穿全图的低对比战术网格与暗灰工业背景 | 不做规划，直接让模型“参考图2把页面填满” |
| **2. 放在哪（空间落位）** | 位于哪个分区、哪个坐标范围？与角色和正文保持什么距离？ | 主字组置于首屏左下方暗部（避开角色脸与武器）；章节底条置于每段正文顶部并左对齐 | 位置随意，导致生成的装饰压住正文或挡住角色脸部 |
| **3. 起什么作用（视觉职责）** | 它是第一焦点、第二焦点、引导视线、分隔模块，还是纯粹承托文字的安静底板？ | 主字组承担首屏第二焦点；章节底条用于建立长图滑动的阅读锚点；背景只做空间承托，主动弱化对比 | 所有新增素材都画成高饱和发光体，与主角和正文全面抢焦 |
| **4. 怎么制作（原创推导依据）** | 从**当前角色设定或本次活动主题**的哪个部位提炼造型、配色与材质？采用什么画风与质量词？ | 从角色外套的“深灰哑光织物+荧黄警示条+45°切角护甲”提炼几何切角与配色，不用参考图里的金边花纹 | 把风格参考图里的金色欧式边框改成黄色直接套在画面上 |

## 三、实际读图与提示词映射步骤

1. **建立输入清单与权限标记**：
   - 先看所有输入图，逐一标记：`[自有主体：图1]`、`[风格/版式参考：图2]`。
   - 检查哪些素材实际传入了当前调用的工具输入：模型看不到的素材只能由你转化为具体的文字描述，**严禁在 prompt 中对模型不可见的图虚指为“按图3绘制”**。
2. **提取自有角色的“可见身份锚点”**：
   - 不要只写“保持图1角色一致”。必须把关键视觉锚点写成具体词句，例如：“保持图1角色的银白短发、左侧青色机械发夹、深灰高领战术短外套與单把月牙长刀，面部神态冷峻”。
   - 区分同一角色的多视图、不同皮肤或不同角色；设定图上的色卡、尺寸线、三视图标注文字、水印必须明确排除，不带入成稿。
3. **提取参考图的“抽象方法”并写明“点名式隔离指令”**：
   - 当把风格/版式参考图传给模型，或转化为提示词时，必须写清**“借什么、禁什么（点名参考图内的具体物件）”**，不能只写笼统的“不画外部参考物件”。
   - **正确写法示例**：“图2仅作为明暗比例与半厚涂笔触参考：学习其大面积深蓝暗部衬托局部暖金主光的反差关系，以及柔和的体块过渡画法；**严禁出现图2中的人物、骰子、扑克牌、乌鸦、古堡建筑、十字徽章、欧式卷草金框及原有文字**。”
4. **严格隔离“画面内正式文案”与“内部解释/免责说明”**：
   - 缺正式技能数据、活动日期或价格时，交付画面 **只能写面向玩家的游戏内体裁文案**（如“角色故事”“战斗特性：黑羽 · 青晶 · 长杖”“活动时间：待公布”“具体规则及奖励以官方公告为准”）。
   - **绝对禁止**把“背景创意提案”“视觉主题提炼，非技能机制”“灰底示意”等设计师对用户的内部沟通解释写进画面文案中！内部说明只准放在沟通记录或草稿外的设计说明里。
5. **区分四种参考执行模式**：
   - **版式复现（针对用户自有母版或明确要求复刻版式的任务）**：保持分区比例、阅读顺序、主体与字区的空间关系，仅替换为本次指定的我方角色与准确文案。
   - **结构借鉴**：保留层级节奏与动线逻辑（如对角线冲刺构图、左图右文弹窗结构），围绕我方角色动作重新调度场景与元素。
   - **画风迁移**：只迁移绘画媒介、线条、上色、材质高光与色调规律（配合精准画风分类与质量增强词），构图与场景按本次任务全新设计。
   - **局部修改**：严格锁定原图保留区域与修改区域，不跨区重绘已确认内容。

## 四、意图判断、主动拟案与事实边界

遵循优先级：**用户最新明确指令 → 已确认项目约束/角色权威设定 → 本轮指定素材用途 → 设计师专业推导**。

1. **设计师主动拍板的范围（不追问用户）**：
   - 用户未指定具体字体、配色比例、光影角度、构图机位或概念短句时，由你根据角色与品类直接做出最优设计决策。
   - 用户说“参考这张图的氛围，用我给的角色做一张版本海报”——已足够直接执行，无需反问“你想要什么色调或站位”。
2. **严禁越界的事实红线**：
   - 用户说“配色和排版你定”，不代表可以自己编造“公测日期 10月1日”“首充6元送SSR”“免费领100连抽”“全新开放世界玩法”等未提供的商业与玩法事实。
   - 缺少正式活动文案时，可拟定贴合角色世界观的概念主题词（如“星环回响”“破晓集结”），并在回复中说明这是提案文案；涉及价格、日期、概率位时，若用户未给具体数字，只设计视觉底板或使用通用占位表述。
3. **何时才需要提问**：
   - 仅当存在会导致作品直接作废的硬冲突时才问一个精准问题：例如上传了多套互斥服装却未说明用哪套、多角色未说明谁是主推且无法从主题判断、要求原样使用官方 Logo 却只给了极模糊的残缺截图。

## 五、多轮修订中的锚点保护

当用户对生成结果提出局部修改意见时，**只修改被批评的变量，锁定其余已确认的设计资产**：
- 用户说“背景太乱，参考图的平涂感更强” → 收敛背景细节、加强平涂色块感，**保留已确认的角色动作、身份特征与文案布局**。
- 用户说“标题字太普通” → 重新设计字形骨架、字组错落与主题母题，**不擅自删改标题原文或更换角色**。
