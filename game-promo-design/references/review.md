# 质量验收、问题诊断与定向修订

工具调用成功、图片生成完成，不等于设计合格。本文件规定**草稿阶段自检**与**成图三尺度验收**的可观察标准，以及出现缺陷时具体改哪里、怎么改。

---

## 一、草稿与版式方案阶段自检（生图前必查）

当输出 H5 长图草稿或多模块版式方案时，在交给用户选稿或进入正式生图前，逐条核对：

1. **信息与模块完整性**：用户要求的章节、角色、核心文案是否全部在草稿中有明确落位？需制作和复用的素材是否完整列出？
2. **拒绝“标题+空框”与“大块空洞/矩形阶梯”**：每个章节是否通过合理的底板形状、多列组件或视觉信息卡体现了紧凑饱满的版式结构？避免下半屏出现近半屏空置底色，也不用生硬的矩形阶梯块充当过渡。若原角色素材带灰底/实色底，是否在方案中明确“正式画面消融灰底并融入连续场景”？
3. **文字边界、三级字号层级与纯洁性（零容忍项）**：
   - **三级字号层级**：首屏主标题草图字号（约 `56–72px`）是否显著大于后续章节标题（严格控制在 `36–44px`，绝不设成 60px+ 与主标题抢戏）？正文（`28–34px`）与底部规则说明（`≥24–26px`）是否满足移动端直读要求？
   - **边界安全**：所有正文与标题是否严格留在所属底板或安静区域内，留足内边距（无越框、无压线、无遮挡脸部）？
   - **严禁内部说明入画**：画面上的文字 是否 100% 为面向玩家的正式宣发文案？**有无把“背景创意提案”“视觉主题提炼，非技能机制”“普通字形占位”“1080×1400”等内部解释或工程说明写进画面？**（放到画面外的设计说明）。
4. **待生成素材槽（Slots）与方向描述**：
   - 独立标题预留区的宽高比和位置是否符合整个字组（含辅助小字）的实际体量？
   - 版式说明与制作指令 是否写出了量化的大小字错落比例、平面字反浮雕/反金边负向约束、14类精准画风名与质量增强词？

## 二、成图三尺度看图验收

严禁不看图就宣称“设计精美、文字准确”。必须按以下三个尺度依次检查：

### 1. 缩略图尺度（一眼抓焦测试）
- 把图放到实际投放/浏览的小尺寸观察：
  - **第一焦点是否唯一且瞬间可辨？**（主角脸部/核心动作或主奖励是否明显领先于周围环境？）
  - **主标题是否清晰跳出？**（有没有因为背景太亮、太花或外发光太糊，导致标题缩小时融进背景看不清？）
  - 如果缩略图看起来只剩“均匀铺满全图的亮边、碎线、噪点和光斑”，判定为**主次失衡（需修订）**。

### 2. 全图关系尺度（构图、融合、疏密与参考边界）
- **视觉融合（有无拼贴感）**：
  - 角色、道具、标题与背景的光源方向和环境色温是否统一？
  - 角色与背景交界处有无环境反光、轮廓光或接触阴影？（是否像把一张立绘生硬贴在毫无关系的背景墙上？）
- **疏密三分区（有无拥挤或空洞）**：
  - 精细区（脸/武器/主标题）、支撑区（中景结构/次要元素）、安静区（正文底板/轮廓外围）是否各司其职？
  - 正文阅读区背后是否足够安静？有没有出现毫无意义的死白/死黑大空洞，或者连落脚处都塞满碎石与边花？
- **参考图边界核查**：
  - 画面里是否出现了从外部风格/版式参考图里直接照搬或改色重画的**具体角色、特定道具、Logo、建筑或专属边花**？一旦发现，必须判定为**参考越界（必须重做该部分）**。

### 3. 原生像素尺度（放大核对）
- **逐字认读准确文案**：
  - 将标题和关键文案区域放大到原图像素，**把实际看到的每个字原原本本读出来**，与目标文案逐字比对。
  - 重点排查：复杂汉字右半边或内部笔画变成花纹、多一笔少一笔、同音错字、多画了一遍重复的副标题、或混入无意义的乱码英文。
- **艺术字造型质量**：
  - 标题是否有明确的字形骨架设计与字组错落节奏？是否退化成了“普通等大黑体字 + 金属贴图/多层描边/大外发光”？
- **角色身份与结构**：
  - 脸部神态、发型瞳色、服装结构、手部指节、武器连接处是否准确连贯？有无兵器穿身或肢体错位？
- **透明素材边缘与 Alpha 报告判读（针对 `transparent` 素材）**：
  - 将同一透明图分别叠在白底和深底上。观察字面是否扎实，字外与字腔是否干净，边缘有无色边或矩形雾底。Alpha 为 254 的近实心像素和 Alpha 为 1 的弱残点都属于部分透明，应结合局部像素分布和实际观感判断。

## 三、问题诊断与定向修正对照表（出现问题具体怎么改）

发现问题时，先指出**具体画面位置与可见原因**，再按表中方法精准调整提示词、参考映射或排版参数，不盲目整套推翻：

| 观察到的具体缺陷 | 根本原因诊断 | 具体修改动作（改哪里、怎么写） |
| --- | --- | --- |
| **艺术字像普通字加金属边/发光，俗套廉价** | 提示词只写了材质/描边/发光，没写字形骨架与字组结构，或滥用了立体配方 | 重写标题 prompt：① 明确字面高宽比与笔画特征（如高对比明朝体/刀锋斜切黑体/苍劲飞白行书）；② 明确字组主次错落（核心字放大、连接字缩小嵌合）；③ 删掉多层描边与强外发光，只留一种契合题材的主材质与 1 个角色提炼母题 |
| **标题下方多出一行生硬小字或重复文字** | 独立标题已含辅助短句，整页又画了一遍；或无脑加了“角色视觉设计”模板字 | 检查并删去无意义的假副标；若已有透明标题字组，在整页 prompt 中写明“直接使用已传入的透明标题字组，禁止在标题下方额外生成重复小字或装饰字幕” |
| **人物、背景、标题像三张图硬拼在一起** | 缺少统一主光源描述、缺少接触阴影/环境光互染、标题直接浮在杂乱背景上 | 在 prompt 中补入：① 全图统一主光方向（如右上暖金逆光）与环境暗部色温；② 角色边缘受环境光染色、脚底/贴合处有清晰接触阴影与前景烟雾/光带穿插；③ 标题背后做局部柔和压暗或定制底板承托 |
| **画面太满太乱，到处是碎光、飞石和花边** | 提示词堆砌了过多同级特效与装饰词，挤占了安静区 | 删除提示词中次要的粒子、碎石、法阵、繁琐边花描述；明确写出“主体轮廓外围与正文区保持低对比纯色/柔和暗部安静区，细节仅集中在主角面部、武器与主标题” |
| **画面局部空洞、干瘪，缺少完成度** | 只有孤立人物和单调纯色底，缺少中景支撑结构、光影渐变与画风质量词 | 保持安静区不乱的前提下，为背景补充柔和的空间光影层次、细微材质肌理或1处概括的远景剪影结构，并补齐对应细分画风的**质量增强词** |
| **误把参考图里的道具/花纹/建筑画进了新图** | 将风格/版式参考图直接传给模型时未加隔离约束，或提示词照抄了参考图物件 | 在 prompt 中明确写出“图N仅作光影/版式参考，严禁绘制图N中的【具体道具/建筑/边花名称】”，并替换为从我方角色提炼的原创元素描述 |
| **长图或弹窗文字越出底板、遮挡角色或过小** | 草稿坐标/宽高估算不当，或整页生成时未给正文留足安静底板 | 调整草稿的文字位置、容器尺寸和字号并重新检查；整页 prompt 中明确指定各章节文字底板的留白范围与对齐方式 |
| **标题或正文出现错字、漏笔、粘连** | 字数过多、笔画过繁，或特效/裂纹切断了关键笔画 | 减少笔画上的裂纹/切口/火焰遮挡描述，强调“每个汉字笔画结构完整准确、字腔清晰”；独立标题槽单独重新生成并核对无误后再进整页 |

## 四、有控制地执行修订

1. **优先解决最影响交付的硬伤**：错字、漏人/串脸、挪用参考图具体物件、文字越界、主次完全失焦属于最高优先级，必须修正。
2. **锁定已成功部分，单变量精确调整**：如果独立透明大标题已经验收合格，只重做整页合成；如果草稿只有第 2 屏文字越界，只更新草稿该章节尺寸与坐标。
3. **核对生成状态**：请求中断时，先查询原任务是否已有结果，再决定如何完成修订。
