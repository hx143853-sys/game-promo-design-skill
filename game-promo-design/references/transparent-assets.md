# 原生透明素材：画法与质量

适用于新建透明道具、头像框、徽章、角色、字组/Logo，以及用户允许重画的透明版本。需要保留原图像素时，使用原图去底流程并保留原画风。

## 风格要能照着画

先看用户的真实参考，分清身份素材和风格参考。仅供风格学习的图只提取画法，不搬用其中角色、道具、Logo或具体装饰；只有用户明确指定某对象为素材时才使用其身份。没有参考就按用途选定画法，用户已委托的细节自行决定，不新增问卷。

把适用的以下信息组成连贯的风格描述，写入实际出图提示词。

| 维度 | 写清什么 | 避免只写 |
|---|---|---|
| 媒介与体积 | 2D赛璐璐、概括笔触的数码厚涂、平涂图形、像素、写实CG等，并说明体积来自色块还是渐变 | 二次元、手绘、游戏风 |
| 轮廓与线条 | 有无描线、粗细变化、线色、硬软边分配；像素素材的阶梯边与像素颗粒 | 线条高级、轮廓精致 |
| 明暗与上色 | 如主体一层基色配两组清楚阴影；或大色块塑形、局部软过渡；暗部是否偏冷 | 电影级、高级渲染 |
| 材质与高光 | 金属窄亮边/深反射区，珐琅平滑色面，晶石大切面，布料柔和折面；各材料要有区别 | 质感好、细节丰富 |
| 光照与配色 | 主光方向、软硬程度、主色面积与点缀位置，亮点集中在哪一处 | 梦幻、炫酷 |
| 细节密度 | 主轮廓与大块面优先，纹理/雕饰集中在选定部位，缩到使用尺寸仍可读 | 极致细节、超复杂 |

这些是描述维度，不是每次机械填满的栏目。风格类别只是起点：“二次元”后还需要实际线条、上色与材质；不确定的参考特征不要编造。有意的厚涂笔触、颗粒、像素阶梯、风格化轮廓都不是瑕疵，不能为了“干净”全部磨平。

## 独立素材先写清保留什么

- 用户要独立角色、头像框或单个道具时，先用自然语言说清本张允许出现的主体、附属件与光效，再点名排除参考海报中的宣传标题、独立Logo、名牌、场景和无关物件。不能只写“排除未列出的东西”，同时又笼统要求“保留所有准确文字”。文字或Logo本身就是目标时，按用户指定文字保留，不套用无字要求。
- 同一张海报可承担不同职责：角色素材锁定身份和服装；新头像框、道具只学习已指定的画法、材质和配色，不连带复制人物、文字或宣传构图。把每张真实参考的职责写进各自实际提示词，不能依赖上一张提示词或助手对话让图片模型自行继承。
- 用户要求主体带光效时，把光效限定到具体部位，例如发梢轮廓光、头像框边缘的能量裂隙、武器转轮的发光部件，写明范围与淡出方向。没有要求独立特效层时，光效随该主体同图生成，不另加一次出图。
- 用户单独要一张特效素材时，明确仅保留光迹、粒子或指定光晕，不带承载它的标题字形、人物或背景。描述“标题交叉的闪光”时，补充“只要光迹，不要文字笔画；被字遮挡处连贯补齐”，避免把整个字组当成特效。
- 用户明确要三张独立素材，就在既有任务中交付三张；不能擅自合成一张素材表或额外拆出光效图。这不改变完整图片分层的分组、合并出图或请求数量规则；分层仍遵守用户选定的方案，不把独立素材测试推广为每个图层都单独生成。

## 基础质量要落在可见结果上

每次提示词都覆盖**主体结构、与选定画法相容的边缘、透明区域**；再按对象补镂空、细线或光效要求。可用“清晰、干净、完成度高”概括目标，但紧接具体含义，不只堆 `masterpiece / best quality / 8K / 无瑕疵`，也不写不存在的权重或 negative 参数。

- **完整和清楚**：主体结构与零件连接合理，轮廓不重影、不粘连，材质边界明确；没有非设计所需的糊块、脏点、杂线和漂浮碎屑。生成完整独立素材时给尖端、发梢、外饰和需要的光效留空间，不被画幅裁断；用户指定裁切构图时尊重裁切。质量提升不等于增加雕花、粒子、锐化或镜面高光。
- **硬边质量**：非像素素材的硬质外轮廓清楚连续，抗锯齿过渡窄而平滑，不出现非设计性的锯齿、毛边、重复轮廓或过度锐化亮圈。像素风保留有设计的像素阶梯，不要求平滑模糊。
- **透明底与色边**：无实体/软效果的外底及真实孔洞完全透明，不绘制白底、黑底、灰底或棋盘格；边缘不残留抠图底色、白边、黑边、灰边或彩色污染。原设计的描边、金属亮边、轮廓光属于主体，不能误删，也不能将正常黑色描线视为黑边污染。
- **透明度层次**：不透明的脸、衣服、金属、文字笔画等保持扎实，暗色不是透明依据；发梢、羽毛细边、薄纱和光晕按材质自然过渡，不把整个人物、整簇头发或整块衣服半透明化。不能用全部硬切来追求“干净”。
- **细小结构**：细柄、链条、丝带、羽轴、字的细笔画保持连续，真实缝隙分开；不把内部高光、白色花纹或深色阴影误挖为空洞。孔洞依据结构，不能仅按亮暗判定。
- **软效果**：需要的辉光局限在指定发光部件附近，由亮到透明自然衰减，不连成灰雾底板或有矩形边界的半透明贴片；不为非发光素材自动添光效。用户要求无光效时直接省略。

## 按对象选择重点

| 对象 | 重点写进提示词 | 容易混淆的边界 |
|---|---|---|
| 独立道具 | 主形和附件可辨、切面/连接完整、材质区分、细柄细链连续；无多余底座或承托场景 | 游戏内带底板图标与独立透明道具不同，不自动添加稀有度底板 |
| 头像框 | 框内孔与框外均透明，连接完整，装饰留在外圈，内缘也无灰雾/底色 | 不画头像、中心板、玻璃片或假透明渐变；开口比例按使用场景确定 |
| 徽章 | 中心符号清晰、实心底板保留、外轮廓干净，等级有辨识度 | 实心徽章不套头像框中心挖空规则 |
| 透明角色 | 肢体/服装/装备结构连贯，面部清楚，发梢羽翼细节完整，实体不穿透，软硬边分工 | 允许重画不等于逐像素保真；原图去底不补画原图未出现的部位 |
| 标题/Logo字组 | 精确文字、笔画连续、字腔与字间空隙透明，字效与主体分层清楚，细字不糊 | 有意底牌/连笔/投影按设计保留，不为“干净”随意删字效或改字形 |

## 提交与效果判断

- 提示词写画面目标；模型、比例、分辨率、质量档位与 `background:"transparent"` 采用工具实际支持的参数。增加质量描述不表示升档，不改变用户选定的模型与规格。
- 提交前检查实际 `prompt` 已写入选定的具体画法、适用的质量标准和参考职责；明确描述成品边缘应该怎样呈现。不把整份资料逐字粘贴进每个请求。
- 程序的 Alpha 报告只能证明文件透明情况，不能证明锯齿、色边、细节和画风已合格。PNG扩展名与画出的棋盘格也不证明透明。
- 分别在白底与深底查看实际图片，必要时检查局部 Alpha 分布。透明像素内可能保留灰色、红色等隐藏RGB，不能把忽略Alpha的显示直接判成可见雾底。观察硬边、软光、孔洞与有无混入非目标元素；缺少证据写未核实，不凭提示词或文件成功宣称无瑕疵。
- 部分透明像素的计数同时包含 Alpha=1的弱残点和Alpha=254的接近不透明像素。全部可见像素属于这个计数，不足以断言主体严重穿透；按工具给出的数值范围、分布和叠底外观说明程度。接近不透明不等于严格不透明，低Alpha也不等于可以忽略，不能因此自动记质量通过。
- 全图统计不定位头像框内孔、实体或某条细边。需要这些局部结论时直接检查该区域；统计只代表该取样范围，不能用一个中心点证明整个内孔完全透明。按原尺寸检查细边，缩略尺寸检查可读性；发现问题说明位置，不自动清零低Alpha、把主体Alpha拉满、重画或追加去底。原图去底同样需要多背景验收。

## 写法示例（按实际题材替换，不是固定模板）

以下是指导性片段，不是新一轮模型实测结果；主体设计、构图、准确文案、参考图职责仍需结合任务补齐。蓝金配色和手绘画法仅用于展示描述精度。

**道具：**
> 采用2D手绘游戏道具画法，深蓝细轮廓随转折略有粗细变化，大块明暗塑造晶石体积，切面内只做短距离柔和过渡。金属扣件用窄暖色亮边和深反射区，晶石用清楚的大切面、冷色暗部与一处明亮内核，减少细碎刻线。主体结构完整，尖端留在画幅内；轮廓连续，硬边有窄而平滑的抗锯齿过渡，无多余毛边、重影、杂点或底色残边。细连接件不中断，真实空隙透明，实体内部保持扎实；仅内核附近保留少量自然淡出的光晕，其余外底完全透明，不加底板或地面。

**头像框：**
> 二维绘制的珐琅金属头像框，以清楚的深色外线、平整珐琅色面和少量硬边阴影表现厚度，金属倒角集中窄高光，不做满框写实镜面反射。框体接合清楚，装饰集中在外圈，细小结构在缩略图仍可辨；内外轮廓连续平滑，无非设计性的白边、黑边、灰雾与重复轮廓，保留正常深色描线。中心头像开口和框外都完全透明，中心不放人物、底板、玻璃片、阴影或渐变；不让装饰伸入面部显示区。

**允许重画的透明角色：**
> 图1是用户指定的角色素材，保留脸部辨识、服装结构、主配色和标志性装备。沿用参考的细深色轮廓、大块清楚的赛璐璐阴影、发束内少量渐变和局部金属亮边，不添加写实皮肤毛孔、满身碎反光或新装饰。肢体与装备结构连贯，保留细发束、羽轴和飘带，彼此间真实空隙透明；脸、衣服与装备实体保持不透明。硬质边缘清楚，发梢与羽缘自然过渡，不糊成半透明雾团，不产生底色残边或剪纸硬切；外底完全透明。这是参考重画的透明版本，不作为原图像素不变的抠图。
