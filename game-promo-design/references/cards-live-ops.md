# 运营活动

运营图在游戏里被看：屏幕小、停留短（1–3 秒），玩家要立刻知道“这是什么活动、我能得到什么、点哪里”。所有运营图共同原则：**奖励要看得见、按钮要找得到、氛围要像这个游戏**。

## 拍脸弹窗（登录即弹出的大图推广）
- **成功标准**：一秒内让玩家产生“想要”——想要角色、皮肤、礼包或参加活动，且一眼看出这是**游戏内高完成度破框弹窗**而非普通全屏壁纸。
- **做法**：
  - **破框弹窗结构（Out-of-Bounds Pop-up）**：画面中央构建一个契合游戏世界观的异形切角/金属镶边弹窗面板（占画面约 75%–82%，弹窗外围四周压暗为深色半透明环境遮罩）；角色上半身、飞扬长发、巨翼或武器**大幅冲出弹窗的顶部与左侧边框**，制造强烈的 3D 破框跃出感。
  - **三层高转化信息舱**：弹窗另一侧（或下半区）集中排布：① 极具冲击力的定制主艺术字组；② 1 个聚光灯下的核心奖励展示台（或主推外观特写）；③ 底部醒目的高对比游戏 UI 按钮（如“立即前往 / 限时获取”，带清脆高光倒角与按钮厚度），弹窗右上角预留精致的关闭图标位。
- **反套路**：避免“方框里规规矩矩关着一个站桩角色加一行字”，也避免不画弹窗容器直接画成普通插画。
- **雷区**：按钮淹没在背景里；文字和奖励没有底板承托；关闭按钮缺失或被装饰挡住。

## 活动弹窗（登录、签到、充值、抽卡、限时、兑换等）
- **成功标准**：结构清楚可读，奖励一眼看见，同时有本游戏的氛围。
- **做法**：
  - 登录 / 签到：按天数排列的奖励格，后几天（尤其最后一天）的大奖用更大的格子、发光和特殊边框突出，形成“坚持到最后”的期待；已领、可领、未领状态可以用明暗区分。
  - 充值 / 礼包：主推礼包放最大，堆叠的道具、宝箱、货币要有分量感和光泽；价格位置清楚（无真实价格时只画价格底板，不写数字）。
  - 抽卡 / 限时：主角色或主奖励必须是视觉中心，配倒计时或概率提升的醒目标签位置。
- **占位规则**：没有真实奖励资料时，画符合题材的通用道具（宝石、装备、宝箱、货币、药剂、卷轴）作为占位，不写具体数量和数值，也不留空白格子。
- **雷区**：所有奖励格一样大，没有重点；装饰边框比奖励还抢眼；文字太小。

## 活动横幅（Banner）
- **成功标准**：在细长的条里也能一眼认出活动。
- **做法**：一个角色或奖励（偏一侧）加一个短标题，背景强烈简化；左右两端留安全区不放关键内容。
- **雷区**：塞入多个角色和长文案。

## 公告图 / 活动页头图
- **成功标准**：为下面的正文定调，标题清楚。
- **做法**：横向宽幅，标题区稳定，角色或场景为辅；与本次活动 KV 保持同一视觉语言。

## 赛季 / 排行结算图
- **成功标准**：让人有荣誉感、想分享。
- **做法**：段位徽章或奖杯为视觉中心，配强烈的光效和庆典感；名次与数据位置清楚（无真实数据时只留位置）。

## 礼包卡 / 商品卡
- **成功标准**：在商城列表里一眼区分档次。
- **做法**：同一套卡用统一框架，档位越高框越华丽、光效越强；主道具占卡面一半以上。

## 通行证 / 战令宣传与购买页（Battle Pass / Season Pass）
- **成功标准**：一眼看清本季满级核心大奖（限定皮肤/高阶外观）与“免费线 vs 进阶线”的丰厚超值感。
- **做法**：左侧或上半区以破框大图展示满级皮肤角色与专属艺术字组，右侧或下半区用清晰的阶梯轨道/双行网格展示核心节点奖励，解锁按钮置于视觉动线终点。

## 首充 / 累充 / 月卡与转盘夺宝活动页
- **首充/月卡**：突出“高性价比主推立绘/神兵 + 连续领取价值”，主视觉占 50% 以上，特权条目收纳在安静底板内（无确切价格与倍率时不编造数字）。
- **转盘/夺宝/皮肤池**：中心奖池或主大奖处于聚光灯焦点，外围奖励槽按稀有度色彩（金/紫/蓝）主次分明排布，绝不让外围小格子抢走中心大奖视线。

## 老玩家回归 / 召回活动图（Returnee Event）
- **做法**：传递温暖重逢或新版本启程情绪（同伴伸手相迎、据点灯火重燃），清晰收纳回归专属福利与重返入口。

## 六大高频运营活动版式骨架表（Live-Ops Layout Archetypes）

设计任何游戏内运营弹窗、战令页或活动图时，先从下表选定版式骨架，确保**主体、奖励格与行动按钮（CTA）主次分明，且全画面只保留 1 个核心主艺术字**：

| 版式骨架名称 | 适用运营场景 | 空间切分比例与视觉动线 | 奖励与文字层级组织 |
|---|---|---|---|
| **1. 左主右舱破框式** | 登录拍脸弹窗、新皮肤/新角色限时上架、首充弹窗 | **左区（45%–50%）**：角色或大奖外观放大，头冠/武器/特效突破弹窗上框与左框边缘；**右区（50%–55%）**：深色或半透明切角信息舱 | 右舱上1/4放主标题字组；中部放 1 个核心大奖台（或3枚对齐小道具格）；底部放高对比暖色 CTA 按钮；右上角留出干净关闭按钮区 |
| **2. 阶梯轨道递进式** | 7日/14日登录签到、累充进度、通行证/战令（Battle Pass） | **左侧/上方（35%）**：终极大奖角色立绘镇场；**主区（65%）**：1→7 阶梯格子或上下双轨（免费线 vs 进阶线）横向推进 | 普通节点用统一尺寸与克制底框；**第3天/第7天/满级终极大奖格面积放大 1.5–2 倍**，配专属金边与微光；不留空白格子 |
| **3. 中心聚光转盘/奖池式** | 皮肤夺宝、转盘抽奖、祈愿卡池活动主界面 | **中心（40%）**：最高稀有度大奖置于聚光灯舞台或法阵核心；**外圈（60%）**：6–8 个次级奖励槽沿环形、八边形或双侧弧线对称排布 | 中心大奖配唯一主标题字组；外圈奖励槽严格按稀有度（金/紫/蓝）缩小并降低明度，绝不与中心大奖同权发光 |
| **4. 三档并列对比橱窗式** | 商城限时礼包、月卡/季卡对比、档位直购 | 画面均分为左、中、右三张竖向商品卡（或 1 大主推卡 + 2 小次推卡） | 高价值主推档位卡片高度微抬、边框升级为华丽主题材质，主道具占卡面 60% 以上；卡片标题用简洁纯色次级字号，底部价格底板清晰对齐 |
| **5. 超宽横幅黄金分割式** | 活动中心长条 Banner、公告头图、商城页眉 | **左或右 1/3**：角色胸像特写或核心奖励聚拢；**另一侧 2/3**：渐暗或纯色安静底色承载标题字组 | 仅保留主标题 + 1 句极短副标；左右两侧边缘各留 10% 安全缓冲，不放小号规则字 |
| **6. 荣耀纹章中心对称式** | 赛季段位结算、全服排行榜、巅峰战报分享图 | 中心偏上放置巨型段位徽章/奖杯（占 45%），两侧展开对称旗帜、羽翼或能量光束；下方为整齐的数据铭牌区 | 顶部或徽章下方嵌合锻造金属/烫金主字组；底部数据栏采用高对比等宽数字与简洁标签，背景安静无杂光 |

## 进阶：活动目标、信息层级与布局

### 用行动确定第一焦点

先从已有活动资料确定用户要完成的动作，再安排主次。赠送活动可用主奖励表达价值，角色做情绪入口；新角色介绍可先展示身份与特色，进入角色页是行动；付费礼包应清楚表达商品内容与已确认价格。不存在通用的“人物永远最大”或“奖励永远最大”。

把内容分成首要价值、必要解释、行动入口三层，给出各层的具体位置与对比关系。全画面只设 **1 个核心主艺术字标题**，模块/栏目小标题采用简洁纯色字配轻量底条（不加大型羽翼或繁复金框抢焦），规则与条件小字保持手机端清晰可读的字号底线且置于低纹理安静底板上。多种奖励不应全部放大：主奖励承担焦点，其余用一致大小和对齐方式形成可扫描清单。必要条件虽然次要，也不能因追求干净而隐藏；价格、限时和领取资格仅使用有依据的内容，**严禁将“价格待定内部占位”“创意提案”等设计师沟通解释写进画面文案**。

正例：用户已说明活动赠送一套角色外观，视觉先突出该外观与角色，兑换条件紧靠奖励区，底部保留“前往活动”入口。反例：资料只有“外观活动”，自行画“免费领取”、折扣价和倒计时，改变了活动事实。

### 先匹配游戏界面，再加强表现力

阅读实际游戏截图，观察面板宽高与屏幕占比、圆角或切角、边框材质、装饰密度、图标描边、字体气质和主按钮语言。继承已有的等级关系，而不是仅提取一个配色。华丽角色可以突破面板边缘，但不能遮住关闭入口、主要文案或已有固定控件。

没有 UI 截图时，可以提供风格选项帮助澄清，不能声称“已与现有 UI 完全一致”。若用户明确选择先做氛围底图，并且该交付意图已确认，可按该范围制作；否则先问清，不自行降级为底图。要求准确套入当前界面的最终排版，需要对应截图或尺寸约束。

### 把留白写成可执行占位

布局建议应说明画布比例、内容区、标题行数预期、奖励区、条件与 CTA 区，以及角色朝向和遮挡关系。占位比例是本次方案，不是平台统一规范。

例如横向活动弹窗可让角色占左侧约一半，视线朝向右侧信息区；右上留标题，中部留主奖励，右下留条件与行动入口。角色衣摆可以进入两区交界，但不要穿过文字区。竖向弹窗可改为上部角色、中段奖励、下部行动，不能机械缩小同一横版。

给出精确交付尺寸时，再根据实际文案长度和目标显示尺寸检查占位；没有文字测量或排版工具时，只说明承载区，不能保证所有文字已适配。安全边距按已有 UI、容器和关闭入口决定，不把随意设定的像素数称作官方要求。

正例：“右侧信息区是有切角、描边和内阴影层次的深色面板，文字对比清楚；人物面部最清楚，光效和粒子围绕角色与主奖励。”反例：“整体更炫、更亮、更有价值感”，却让奖励底板、武器、标题和按钮都使用同强度金光。

### 常见冲突的取舍

奖励很多但空间少时，先确认是否能只突出主奖励、把剩余内容放进详情页；不能自行删减必须展示的信息。角色与奖励都重要时，用空间分区和对比层级解决，不要把每项缩得难以辨认。活动标题较长时，先为真实标题保留足够横向宽度，不通过擅自改写关键名称获得留白。
