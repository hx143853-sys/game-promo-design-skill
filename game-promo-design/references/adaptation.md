# 从母版到多尺寸与多用途

## 先确认延展的是尺寸还是任务

同一 KV 的横竖版可能共享传播重点；KV 转买量图、弹窗或 H5 则往往改变观看情境和信息任务。先保留核心身份、色彩与世界观，再决定每份产物突出什么。不能只把所有版本写成“同图改比例”。

每个版位交付独立成品，并写清哪些元素共用。用户要求整套画板或可编辑源文件时，再按交付格式整理。

## 每个版位重新分配空间

| 变化 | 需要重新判断 | 常见失败 |
| --- | --- | --- |
| 横版到竖版 | 主角相对位置、上下景深、标题承载区、完整武器和脸 | 中心裁切丢掉侧面角色，强行挤缩人体 |
| 大画面到小缩略图 | 主要轮廓、脸与标题占比、简化后还剩的核心信息 | 所有细节原样缩小，主角被特效吞没 |
| 四人母版到单卖点投放 | 是否需要保留全部四人、哪个角色/玩法证明卖点 | 自行删掉用户要求必须出现的人物 |
| KV 到弹窗 | 奖励/条件/按钮与游戏 UI 的关系 | 把完整 KV 当弹窗背景，精确信息无处放 |
| KV 到长图 | 信息顺序、分屏重点、过渡、最后行动入口 | 重复拉伸背景，新增用户没要求的活动机制 |

用户明确要求所有版本都保留四人时，这是硬约束。若竖版难以辨认，提出重排队形、减少次要装饰等方案；不能不告知就改成单人。比例与实际像素采用本次目标和当前工具能力，不写死“所有平台通用”规格。

## 明确依赖与制作范围

区分共享设计规范与依赖生成结果：多个版本共用同一个角色集可以独立规划；衍生图必须以已认可母版为参考时，母版是实际依赖。需要母版作为视觉参考时，先取得实际母版图，后续逐张核对衍生作品的连续性。

需要用母版延展时，把已确认的成品和所需参考实际加入每个制作步骤，按工具的素材上限安排批次。

用户要求三个版本就规划三个需要的产物，不额外安排未授权“预备探索图”。

## 系列一致性不是每张完全相同

共享角色身份、官方色、主光逻辑、材质体系和文案事实；允许不同版位改变镜头、局部布局和信息权重。保存被用户确认的母版与规则，并将新的修改限定到具体版本，避免一次投放图优化覆盖整个项目。

完成后按实际状态汇总：成功、失败、取消、运行中与待核实。对每张已读图片核查核心人物、主要信息与实际版位；不能因母版通过就宣称全部衍生图都通过。

成功模式：母版和衍生图认得出同一 IP，每个版位都能读到其主要信息，审批、节点与输出一一对应。

失败模式：所有版位机械裁切，漏人后无提示、低分辨率冒充目标交付，失败或未知任务被自动重复提交。
