# 品牌标识、艺术字组与阵营徽记

凡涉及本品类，**必须同时读取 `craft-typography.md`**（若需透明底交付，再读 `transparent-assets.md`）。

## 1. 游戏主 Logo（Main Game Logo）
- **成功标准**：跨尺寸（从巨幅展板到手机图标角落）清晰可辨，字形骨架与核心图形一眼体现游戏世界观与品类气质。
- **做法**：
  - **先造字形骨架**：武侠/国风用苍劲刀笔或行草飞白；史诗奇幻/SLG 用雕刻感厚重衬线与剑盾切角；机能/科幻用几何切口无衬线与精密倒角；休闲/潮玩用饱满弹性的圆体。
  - **主副结构与中心图腾**：主字与英文副标/版本号抱团成稳定外轮廓（菱形、拱形、倒梯形或紧凑横块）；可将一个核心世界观母题（如剑脊、星环、龙纹、机甲核心）融入首尾笔画或衬于字组中心背后，**装饰不超过字组面积 20%，绝不盖过字形**。
- **铁律**：用户已提供现成官方 Logo 时，**必须原样复用或严格保持其标准字形与比例**，严禁让生图模型自由重绘变形。

## 2. 版本 / 资料片副标与活动主标题（Art Title Lockup）
- **成功标准**：既是可读性极强的准确标题，又是与主视觉光影、角色气质融为一体的第二视觉焦点。
- **做法**：
  - **拒绝“普通等大黑体 + 金属面 + 多层描边 + 外发光”套路**：按 `craft-typography.md` 的四步法——① 定高宽比与笔画切角/连笔/飞白；② 排字组内部大小主次与错落咬合（核心词放大，连接词缩小嵌合，需要的辅助短句与主字抱团成组，**不加无意义的“角色视觉设计”等假副标**）；③ 从当期主角武器或服装提炼 1–2 个结构母题；④ 选择单一主工艺（现代二次元/都市优先平面高对比色块与编辑排版；史诗/奇幻才用克制的锻造金属、晶石切面或熔岩裂隙）。
  - **光影与托底**：受光方向与主画面完全一致；字后通过画面暗部、切角底条或柔和局部压暗托底，不靠大面积外发光糊开。
- **雷区**：每个字一样大排成死板一排；堆砌五层描边和漫天光斑导致字腔糊死；生造错字或把偏旁画成花纹。

## 3. 阵营 / 势力徽记与图腾（Faction Crest / Emblem）
- **成功标准**：剪影独特，即使做成单色印章、旗帜暗纹或金属胸针也能一眼区分不同阵营。
- **做法**：外轮廓采用明确的几何母形（盾形、菱形、环形、六边形、展开双翼）；内部由 1 个核心象征物（狼首、天平、星盘、双剑、机械齿轮）与对称/向心几何线条构成；区分平面矢量印记（适合机能/现代阵列）与立体浮雕纹章（适合奇幻/中世纪/帝国）。

## 4. 赛事徽标与荣誉勋章（Esports & Tournament Crest）
- **成功标准**：兼具竞技对抗张力与最高荣誉感，适合舞台大屏、奖杯铭牌与直播包装。
- **做法**：硬朗对称或向上的V形/盾形护翼骨架，结合锐利的金属切面、能量核心与赛季年份/赛事简称字组；主次分明，边缘锋利。

## 5. 活动角标、印章与标签组件（Event Stamp / Tag Lockup）
- **成功标准**：作为辅助视觉锚点（如“限定”“SSR”“周年特典”“新章开启”），小而精悍、不抢主标题。
- **做法**：使用实色切角底条、朱红篆刻印章、金属铭牌或斜向警示条承载 2–4 个精确字，轮廓封闭利落，紧扣主标题肩部或角色卡一角。
