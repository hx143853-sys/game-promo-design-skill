# 标题字与艺术字组设计（Typography & Lockup）

标题字（Art Title / Logo Lockup）是游戏美宣的第二视觉焦点（在无人物物料中是第一焦点）。最常见的失败是**“拿普通黑体或宋体直接叠一层金属贴图、多层描边、外发光和通用卷草边花”**——这种做法没有字形设计，也没有字组节奏，放在现代二次元、都市、国风或冷峻幻想题材里会显得极其廉价且与画面脱节。

好标题必须按**“一造骨架、二排字组、三融母题、四定材质”**四个层级依次设计。精确文字始终加引号，并明确写出“文字准确、只出现一次，不添加任何多余字符”。

---

## 依据的顺序（不随机挑选，绝不盲目套模板）

1. **用户的明确指定**（指定的字体方向、颜色或明确要求参考某张图的字效）。
2. **参考图中的标题字设计方法**（只借其字形高宽比、笔画特征、字组错落关系和表面工艺；**绝对不抄参考图的原文、品牌名、专属 Logo 图形或照搬其与当前题材无关的具象装饰物**）。
3. **当前角色与装备的造型语言**（无标题字参考时，从角色的服装剪裁、武器廓形、阵营纹样与主配色推导）。
4. **游戏品类与活动主题情绪**（完全无参考时，按题材气质推导）。

---

## 二、第一层：字形与笔画骨架（决定 70% 的设计感）

动笔写提示词前，必须先定义**字本身的几何骨架**，而不是直接写材质：

| 骨架维度 | 可选设计方向与适用气质 | 具体写进 Prompt 的特征描述 |
|---|---|---|
| **1. 字面高宽比与重心** | **瘦长高挑（高重心）**：冷峻、都市、机能、神秘、哥特、先锋二次元<br>**宽扁稳重（低重心）**：史诗战争、重装机甲、SLG、厚重奇幻<br>**方正饱满（中宫外扩）**：庆典、开服公测、休闲竞技 | “字面瘦长高挑，高宽比约 2:1，重心偏上，中宫收紧” 或 “字面宽博稳重，重心下沉，笔画粗壮饱满” |
| **2. 笔画粗细对比** | **高对比（横极细、竖粗壮）**：文艺、剧情章节、现代高定、诡秘、女性向<br>**等线极粗（块面感）**：街头潮酷、买量爆点、机甲、电竞<br>**顿挫变化（毛笔/刻刀）**：武侠、仙侠、暗黑魂系、历史 | “横画极细如锋刃、竖画厚重挺拔的高对比明朝体骨架” 或 “笔画粗壮如碑刻方折，转折处棱角分明” |
| **3. 起收笔与笔画改造（每次选 1–2 处即可）** | **刀锋/斜切角**：笔画末端呈 45° 锐利斜切，收笔拉出尖锋<br>**连笔与借笔**：相邻两字的横画或撇捺贯通相连，形成整体流线<br>**断笔与错位切口**：笔画局部断开或被一道斜线切开并微幅错位<br>**飞白与枯笔**：末笔甩出苍劲的毛笔飞白或墨迹破损缺口<br>**字怀留白改造**：将某个点画或口字框替换为几何星芒、菱形或阵营符号 | “首尾字的主横画向两侧延长并斜切成锐利刃口，中间两字撇捺连笔呼应，点画化作四角星芒，每个字主体字腔保持清晰可读” |

> **铁律**：笔画改造点到为止（通常重点改造首字、末字或核心动词的一两笔），**绝不能把汉字结构改得生造错字或无法辨认**。字数越多（≥5字），单字笔画改造越要克制，改靠“字组排版”出彩。
> **复杂/易混汉字的部件拆解锚点（防错字必用）**：在全景 KV 或大画面中，标题仅占局部区域，模型容易将形近字或上下结构复杂的字画糊（如把“苍”画成“花”、把“临/境/曜/渊/誓”内部笔画粘连）。写 Prompt 时，对易混淆字必须用括号附一句**部件结构锚点**（例如：`主标题“苍羽破夜”（首字“苍”为草字头下接标准“仓”字结构，清晰画出“仓”的人字头与横折钩，勿画成“花”字）`），可显著提升复杂汉字的一次准确率。

## 三、第二层：字组构图（Typography Lockup，拒绝单调一行等大字）

专业美宣标题几乎都是一个**咬合紧密的“字组（Lockup）”**，而不是生硬排成一排的等大文字。

### 1. 主标题内部的疏密与错落节奏（必须写明具体字号比例与方位，防等大横排）
生图模型对四字词或短标题有极强的“等大排成一行”惯性。仅写“大小字咬合”或“临境放大”往往无效，**必须在 Prompt 中直接选用下表中的一种“字组构图样板（Lockup Archetype）”，写出具体的字号比例、分行结构与高低偏置方位**：

#### 六大高辨识度字组构图样板（Typography Lockup Archetypes）

| 字组样板名称 | 适用字数与场景 | 几何结构与具体字号比例（直接写进 Prompt） | 副标题 / 辅助元素镶嵌位置 |
|---|---|---|---|
| **① 左小右大阶梯咬合式** | 4字或5字主标题（如版本名、角色活动名） | **字号拉开约 2 倍的强烈面积反差**：前两字做成紧凑小号字（字高约为主字的 **1/2**，占字组左上方小块区域）；后两字做成超大号核心主字（字高与单字面积约为前两字的 **2 倍**，沉在右下方主视觉区），两组字在中间空隙处上下错位咬合，形成强烈的“小字引出巨字”反差 | 辅助短句加细框或星芒，横排镶嵌在左上方小字正下方的凹槽内，与右下超大字底边齐平 |
| **② 首尾破框中宫收紧式** | 3–5字强张力标题（如动作、武侠、Boss战） | 首字与末字放大至 **130%** 且主笔（长撇、长横或末笔竖钩）向两侧或下方大幅破框延伸；中间字缩小至 **75%** 紧凑收拢在中心偏上位置 | 副标题或切角底条紧贴中间小字下方的拱形留白处，被首尾大字的长笔画左右护住 |
| **③ 双行斜切错位式** | 4–8字标题（如剧情章节、都市潮酷、赛事） | 拆分为上下两行，上行靠左、下行向右错开 **1–1.5 个字宽**，上下行字怀咬合；整体基线可带 **8°–12°** 向右上斜升动势 | 一道贯穿切线或斜切色块底条夹在两行之间，或副标题竖排/小字横排锁在右上角与左下角空位 |
| **④ 主横副竖T型/L型镶嵌式** | 角色名+称号、国风/二次元干员登场 | 核心名称（2–4字）采用超大号横向或紧凑方块的 **130%** 体量；前缀称号、序列号或章节名采用 **35%–45%** 小字号**竖排**镶嵌在主字左侧切口或右侧肩部 | 竖排小字旁配一道极细垂直分割线或一枚小型朱红印章/几何编号牌，整体呈稳固的矩形或L型印记 |
| **⑤ 中心核心字+放射/环抱式** | 含核心单字或数字的标题（如“2周年”“觉醒”） | 将最核心的 1–2 个字（或数字）放大至 **150%–180%** 置于视觉中心；其余文字缩小至 **65%** 分列两侧或环抱于核心大字下半部 | 中心大字背后衬一枚简练的几何星环、盾徽或剑脊母题，副标题收束在底部丝带或切角铭牌内 |
| **⑥ 机能非对称标签群组式** | 现代机能、硬核科幻、情报档案标题 | 主标题字面高挑紧凑（高宽比 2:1），其中 1 个关键字反白压在高饱和斜切色块内，其余字为纯白/纯黑平涂；字组左上与右下紧扣几何准星、微缩刻度线与标签条 | 副标题放入紧贴主字顶部的窄长实色切角底条内，形成严密的工业设计模块 |

### 2. 主标题与辅助短句 / 装饰框的成组关系（Supporting Type）
- **先判断要不要辅助小字**：
  - 如果画面已有明确副标题、英文译名、版本号或活动短句，将其纳入字组统一规划。
  - **严禁机械添加无意义的模板假字**（如无故加上“角色视觉设计”“CHARACTER DESIGN”“NEW VERSION”等用户未要求且无实质意义的填充字）。
- **字组外轮廓抱团规则**：
  - 主标题、辅助短句、编号标签、印章或分隔细线必须**共用一个紧凑的几何外轮廓**（如整体呈倒梯形、菱形、左对齐矩形块或斜切平行四边形）。
  - **禁止“大字占满画幅，再把辅助小字孤零零挤在最底下”**。辅助小字应通过底条、细长横线、引号框或小印章，镶嵌在主标题的上方肩部、下方凹槽处或首尾字侧翼，字号与主标题拉开至少 3:1 的显著级差，字距适当拉开以平衡大字的紧凑感。
- **统一生成原则**：在需要独立透明标题的工作流（如 H5 长图）中，**主艺术字、已确认的辅助短句及紧密咬合的字组装饰必须在同一次透明素材生成中一体完成**，画面上不再重复叠加同一条本地小字。

## 四、第三层：从角色与题材提炼结构母题（拒绝通用贴片边花）

标题的装饰元素必须像是“从这个角色、这个世界里长出来的”，**严禁套用任何题材都能贴的通用欧式卷草纹、对称小翅膀或廉价发光法阵**。

- **提炼方法（只选 1–2 个母题，融入结构而非堆在四周）**：
  1. **看角色武器与剪裁**：剑士的刃口弧度 → 转化为字组底部的弧形斩击切线；机能干员的织带与编号牌 → 转化为字组左上角的斜切警示底条与几何准星；琴师的音律丝带 → 转化为穿插在字间的柔金细流线。
  2. **看角色元素与配件**：火焰/雷电/冰晶/荆棘/羽毛/星轨 → 只在字组的首尾两端或核心大字的转折处生长出 1–2 处局部母题（如末笔延伸出半片晶莹冰棱或两三片散落的暗金羽毛），**不超过字组总面积的 20%，绝不缠满每个字的笔画**。
  3. **看阵营与世界观**：古风门派 → 朱红篆刻闲章或书卷引首章嵌入字尾；赛博工业 → 极细的十字坐标线与微缩条码块压在字组一角。

在动笔设计前，先将当前任务对标到最契合的**主流游戏美宣流派基因**，按其骨架、字组样板、母题与表面工艺组合 Prompt，彻底告别千篇一律的“粗黑体+金属边”：

| 标杆视觉流派 | 典型代表品类/气质 | 字形骨架基因 | 推荐字组样板与母题转化 | 表面工艺与强制负向约束 |

## 六、第五层：题材风格映射与克制的表面工艺细则

确定好“字形骨架 + 字组排版 + 结构母题”后，最后一步才选择表面处理。**遵循“单一主工艺”原则：平面构成好看就不用立体挤出；用了立体材质就不叠五层描边和漫天光斑。**

### A. 平面构成与编辑感字组（现代二次元、都市、剧情、冷峻幻想首选）

> **平面字防浮雕/防金边/防背垫黑影强制规则**：
> 1. 生图模型看到“游戏标题/艺术字”极易自动加上金属包边与 3D 斜面浮雕。**凡选择平面构成流派，必须在 Prompt 中显式写明：“字面内部为均匀单一的纯平涂实色，无 3D 立体挤出厚度、无斜面浮雕倒角、无金色金属外包边、字后无大面积发光雾面”**。
> 2. **严禁自相矛盾描述**：选择平面字时，**绝对不要在 Prompt 中写“用浅灰/蓝灰色面区分笔锋、棱面或切面”**——这类词会被生图模型直接执行为 3D 斜面浮雕！

## 六、全画面三级文字体量铁律（主标题 vs 章节/模块小标题 vs 正文）

在包含多个信息层级的画面（如 H5 长图、运营活动弹窗、角色情报卡、商店多卖点图）中，**严禁把每个模块的小标题都画成首屏主标题那样的巨型华丽艺术字**：

1. **一级：唯一主艺术字组（Hero Title）**：
   - 全图（或长图首屏）**只有 1 个**核心主艺术字组，可占画幅宽度的 65%–85%（720px 宽草稿中字号约 `56–72px`），集中使用定制笔画与主题母题装饰。
2. **二级：章节 / 模块 / 卖点次级标题（Section / Module Header）**：
   - 体量必须显著降级：**宽度不超过画幅的 35%–45%，高度不超过首屏主标题的 40%–50%**（720px 宽草稿中字号严格控制在 `36–44px`，绝不能设成 60px+）。
   - **样式克制**：在 Prompt 中必须描述为“简洁克制的次级章节小标题（干净纯色衬线或黑体字面，仅配一条极细分割线、小菱形前缀或轻量底条，**无大型羽翼、无繁复金框、无重度浮雕与发光**）”，绝不在整页或分段 Prompt 中把章节标题称为“大标题/主标题”。
3. **三级：正文与规则注释（Body & Fine Print）**：
   - 保证移动端（如 375px 手机屏幕）无需放大即可清晰直读。720px 宽草稿中，正文 `28–34px`，辅助规则/说明文字**不低于 `24–26px`**；在生图 Prompt 中明确要求“正文与说明文字字号饱满、笔画清晰，背后保持低纹理安静底板”。

## 七、艺术字提示词必含的质量增强词（Quality Boosters）

在生成含艺术字的画面或独立透明标题素材时，除写清上述 4 层设计外，必须在 `prompt` 结尾补充匹配的**字效质量增强词**：

- **通用字组质量词**：`商业游戏主视觉级定制艺术字组（Custom Game Logo Lockup）、笔画骨架舒展且结构严谨、主副字错落咬合紧凑、字腔开阔清晰、无错字漏字与笔画粘连、边缘锐利干净无毛刺重影`。
- **平面/二次元字组加挂**：`高对比平面构成美学、矢量印刷级利落边缘、色块切分精准、负空间节奏考究`。
- **立体/材质字组加挂**：`细腻真实的材质表面高光、倒角切面干净利落、立体挤出透视准确、光影方向与主画面严丝合缝、辉光克制通透不糊字`。
- **独立透明标题额外必加**：`原生透明背景（Transparent background）、字外底与字腔孔洞完全透明、无矩形半透明灰雾底板、无多余白边或黑边残影`。

## 七、出图后的标题专项验收与修正

制作后放大实际成图的标题区域逐字检查：
1. **逐字认读**：把画面里实际画出来的每个汉字/字母读出来，核对有无比画缺失、多一横少一点、左右偏旁串位或把偏旁画成花纹。
2. **结构与字组检查**：是否又退化成了“四个一样大的普通黑体字排成一排+金属边”？辅助小字是否和主字脱节或重复出现了两遍？
3. **融合与可读性检查**：放在背景上缩小时，标题是否一眼跳出？有没有被背景的亮光、武器或过多特效切碎？
- **修正方法**：若字形平庸，重写 prompt 中的**高宽比、笔画切角/连笔特征与字组大小错落关系**；若字被特效糊住，明确删减外发光与粒子描述，改为**“干净利落的字面轮廓 + 字后局部压暗托底”**。
