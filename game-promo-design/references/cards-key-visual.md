# 宣传主视觉

## 版本 / 活动 KV
- **在哪被看**：官网首屏、商店头图、社媒置顶、版本公告、线下大屏；常被裁成横竖多版。
- **成功标准**：一眼说清“这个版本的主题是什么”，并让老玩家想回来看。主角、标题、世界观三者形成一个画面。
- **做法**：选版本主题里最有戏的一个瞬间（新 Boss 现身、主角觉醒、两派对峙、新地图揭幕）。机位要有态度：低机位仰拍显力量、俯冲视角显速度、极近特写显情绪。标题与动作融合：被武器劈开、被能量照亮、从场景结构里长出来。远景交代新内容（新地图、新敌人）的轮廓，但对比低于主角。
- **反套路**：避免人物站左标题放右、主角正面站桩、背景堆满建筑。可试：主角背对镜头面向巨大敌影；标题作为场景中的巨型石碑；画面被一道斩击斜向分割。
- **字效**：字形从版本主题和主角装备推导（剑士用锋利切口，法师用符文光纹，机甲用金属铆接）；标题常占画宽 1/3–1/2。
- **雷区**：副信息写太多；标题压住脸和武器；多角色时全员同等大小。

## 周年庆 / 节日海报
- **成功标准**：节日氛围与游戏世界观结合，而不是把节日元素贴在角色旁边。
- **做法**：让角色在世界观里过节（暗黑世界的周年是篝火祭典、仙侠的春节是灯火满城）；数字（如“2 周年”）做成画面主角级的设计元素：由道具、光、建筑组成。
- **雷区**：彩带气球式的通用节日装饰；节日元素与画风冲突。

## 角色宣传海报 / 新角色、新皮肤上线
- **成功标准**：让人记住这个角色的个性，并想抽或想买。
- **做法**：用一个最能代表性格的动作或表情（冷傲回眸、豪爽大笑、技能释放瞬间）；服装与皮肤的卖点部位（披风、武器、特效）占据视觉中心；背景用角色的元素属性和色彩呼应。皮肤图要让新外观的细节清楚可见。
- **反套路**：避免标准三分之二身站姿；可试局部特写加全身剪影、技能光效包裹全身、镜面或水面倒影。
- **雷区**：脸被特效遮住；角色识别特征（发型、配色、标志物）丢失。

## 联动海报
- **成功标准**：两个 IP 都能一眼认出，又像是同一个世界。
- **做法**：找两者的共同点或戏剧冲突（并肩作战、交换武器、对峙），统一光照和画风；双方 Logo 位置对等。
- **雷区**：两边画风割裂；一方明显被弱化（除非用户要求主次）。

## 预热 / 倒计时海报
- **成功标准**：制造悬念，让人想知道下一张。
- **做法**：只露局部（剪影、眼睛、武器一角、阴影中的轮廓）；系列各张保持同一版式，倒计时数字做成醒目的设计元素。
- **雷区**：信息揭露太多，失去悬念。

## 开服 / 公测海报
- **成功标准**：大、亮、有庆典感，同时清楚交代游戏类型。
- **做法**：主角阵容冲向镜头或集结于高处，世界全景作背景；“开服”“公测”字样醒目、日期清楚（用户提供时）。
- **雷区**：没有交代游戏玩法类型，像一张普通插画。

## 电竞赛事 / 巅峰对决主视觉（Esports & Tournament KV）
- **成功标准**：强烈的竞技对抗张力与最高荣誉感，奖杯/徽标与双方代表角色形成剑拔弩张的视觉中心。
- **做法**：采用左右阵营对峙、中心奖杯/赛事徽标破光而出的对称或斜切构图；双色对抗主光（如冷蓝对炽红、暗金对银白）统一照亮角色边缘；标题采用硬朗切割黑体或锻造金属徽记字组。

## 世界观先导概念海报 / 大型资料片 KV
- **成功标准**：用极强的空间尺度反差讲述新大陆、新纪元或宿命史诗。
- **做法**：以渺小但剪影坚定的主角背影/侧影对照宏伟奇观（巨神遗迹、深渊裂谷、星际环带），利用大气透视与体积光束拉开前中后三层景深，标题字组融入天空或巨构暗部。

## 进阶：构图、人物关系与光色

### 先决定观众在哪里看、先看谁

一张 KV 的角色数量不等于焦点数量。根据用户主题选择主角、支撑角色和舞台关系：谁承载核心幻想，谁提供互动或规模，背景说明什么世界。没有主角时可以采用明确的群像秩序，但不要无意中把所有脸、武器和特效设为同等强度。

使用面积、明度差、色彩差、清晰度、遮挡和视线方向共同引导阅读。单独把主角放大并不一定有效：主角背后若有最亮、最锐的碎雪，焦点仍会跑到背景。

成功模式：缩小后仍能指出第一焦点，主副角色轮廓可分，背景的高对比区域帮助主体而非与其竞争。

失败模式：每名角色都正对镜头且大小相同，剑尖、头发和建筑边缘互相贴合，粒子遍布所有深度。

### 机位和姿势是空间关系

低机位由地平线位置、地面视角、近远尺度差、身体透视与遮挡共同建立，不能只写“仰拍”。低角度白模参考尤其要保留承重脚、髋肩倾斜、躯干扭转、手部方向以及人物前后关系，再替换为真实角色身份。

构图参考的动作不应迫使角色更换专属武器或服装结构。姿势严重遮挡脸部但任务要求清楚露出主角时，说明需要兼顾的冲突，以小幅转头或调整镜头解决，不把用户要求全部推翻。

多人物可借三角、对角线或环形组织，但这些是选择，不是固定公式。根据故事决定人物互相看哪里、动作互相响应什么。将近景动作压向观众时留出必要的手脚与武器空间；交付比例改变后重新检查。

### 明度、色彩和光线共同建立层级

先分离主要明暗块，再选择符合游戏的色相与材质。冷背景暖主体是可选手段；角色官方色或雪山自然光有约束时，使用局部明度、背景简化、边缘控制也能分离，不能一律染成青橙色。

写出一个合理主光方向，辅光与环境反射解释暗部。不同角色即便来自不同素材，也应进入同一个照明空间；特效可自发光，但不要使每个人同时拥有互相冲突的强轮廓光。

高频纹理优先服务脸、重要装备和核心叙事，远景随距离减少对比和细节。景深虚化不能代替空间合理性，也不能把所有非主角都糊到无法辨识。

### 例：雪山 KV “雪太乱、脸不清、没有重点”

这是说明性例子，不是已经验证的商业案例。

先读取实际图确认问题的位置。若面前密集雪粒与高亮背景抢夺注意力，可提出：保持雪山与原有角色关系，减少主角脸和身体轮廓前的中小雪粒，将较大前景雪放在边缘且降低清晰度；拉开主角脸部与身后背景的明度差，远景山体减少碎纹理。保留少量雪的方向表达风势和空间。

评审要看脸是否更清晰、轮廓是否从雪山分离、第一焦点是否更稳定。不能把“清理雪粒”固化为所有雪景都必须少雪，也不能在未看图时断言修改成功。

### 标题区也是构图内容

根据已知标题/Logo 的长度和层级规划标题区。标题区不必是空白：渐暗的天空、虚化的背景、一块切角底板或徽章都能托住标题；特效和武器可以从字后穿过，但不盖住字的主体笔画。文字尚未提供时使用布局说明，不能虚构正式文案。

主次清楚不等于画面寡淡。游戏 KV 需要冲击力：镜头、前景层次、光效和标题体量要足，主次靠主体和标题最亮最锐来建立，而不是把整张图压成低细节。

小尺寸可辨识性、横竖衍生裁切和实际显示环境影响构图。保留主要人物完整动作、重要设备轮廓和可重排空间；四周机械留同样宽度不能保证所有版位适配。
