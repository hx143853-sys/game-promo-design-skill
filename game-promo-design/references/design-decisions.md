# 游戏平面设计决策、视觉融合与正反案例

用于画幅与用途决策、解决缺乏创意、消除“人物+背景+字”拼贴感、处理多信息拥挤及保障构图草稿质量。

---

## 一、按交付用途确定核心设计目标

比例仅作方案起点；优先服从已确认尺寸、实际界面容器和渠道规范。

| 交付用途 | 核心视觉目标 | 画幅与版式取舍重点 |
| --- | --- | --- |
| **宣传主视觉（版本/活动/赛事KV）** | 建立强视觉记忆点，人物、标题与世界观融为一体，支持横竖延展 | 横版展开空间叙事与群像层次，竖版强化前后景深与高低错落；预留可裁切安全区 |
| **角色海报 / 新皮肤 / 出金立绘** | 瞬间传达角色性格、核心幻想与外观卖点 | 顺应武器与动作张力选横竖版；服装材质、标志物与面部神态必须处在第一焦点 |
| **运营弹窗 / 拍脸 / 战令 / 礼包** | 1–3 秒内看清“核心价值（奖励/角色）+ 参与条件 + 行动按钮（CTA）” | 服从游戏内弹窗容器比例；主奖励或主推角色占 40% 以上，条件与按钮落在安静底板上，留出关闭区 |
| **买量投放图（信息流/开屏/抉择钩子）** | 小屏滑动中 1 秒停驻，只讲透一个真实可感的卖点 | 1:1 / 4:5 / 9:16 / 16:9 按版位重排，绝不直接裁切 KV；卖点结果（如清屏、进化对比、福利堆叠）放到最大 |
| **静态 H5 长图 / 版本专题长页** | 竖屏滑动节奏分明，首屏镇场、中段模块化叙事、尾屏收束转化 | 固定宽度，按章节内容决定总长；段与段用光影、云雾、斜切结构或场景自然衔接，忌做成多张独立海报硬拼 |
| **社媒图（情报卡/日历/九宫格/封面）** | 信息好读、适合转发讨论，兼具官方审美与社区亲和度 | 角色情报卡与版本日历强调整齐的网格、标签条与图标系统；视频封面强调特写情绪与大字反差 |
| **游戏内平面素材（图标/框/徽章/UI）** | 缩到实际游戏尺寸仍一眼可辨，成套风格、光源与稀有度等级统一 | 独立透明素材严格遵守边缘与孔洞透明规范；UI 面板保证功能分区与文字可读性优先于繁复雕花 |
| **品牌标识 / 艺术字组 / 阵营徽记** | 独特字形骨架与世界观符号结合，跨尺寸清晰可识 | 先定字形高宽比、笔画改造与字组错落轮廓，再定单一主材质；已有官方 Logo 资产时严禁模型重绘变形 |
| **线下与衍生品（展板/立牌/镭射票/吧唧）** | 匹配真实物理载体视距、裁切出血线与印刷工艺特点 | 展板/易拉宝避开底部遮挡区；立牌/挂件保证外轮廓剪影闭合清晰；徽章/镭射票贴合圆形或窄长画幅构图 |

## 二、把创意落到可见的画面关系（拒绝站桩与套路）

从当前角色、装备、玩法和主题中选择一个明确的**视觉主机制**：

1. **决定性叙事瞬间**：抓动作爆发前蓄力或爆发刹那（剑刃出鞘半寸、转身回眸对视、踏碎地面跃起），用视线方向与动作线连接画面各元素。
2. **戏剧化尺度反差**：前景局部特写（如横过镜头的刀锋、飞散的符纸、巨型 Boss 的利爪阴影）与中景角色或远景巨物形成强烈大小对比，建立空间纵深。
3. **主题图形秩序**：从角色自带的圆环、折扇、机能斜线、荆棘、星轨或阵营图腾中提炼几何骨架，作为分割画面、承托标题和串联章节的统一秩序。
4. **图文穿插咬合**：让角色的披风走势、武器挥砍弧线与标题字组的外轮廓呼应或局部前后穿插（发梢/光带掠过字外装饰，但不切断主字笔画）。
5. **克制的静态张力**：冷峻、悬疑或高定风格可用极致的构图留白、剪影切割、凝视对峙或仪式感对称建立张力，不盲目堆砌爆炸与粒子。

## 三、视觉融合四要素（彻底解决“人物+背景+字”拼贴感）

当画面出现“角色像贴纸、背景像另一张图、标题像后加的 Word 字”时，必须从以下四个物理与视觉维度强制融合：

1. **单一主光源与光影自洽**：
   - 全图明确一个主光源方向（如左上方冷月光、右后方暖金逆光、正下方熔岩火光）。
   - 角色的受光面、衣服褶皱亮边、武器反光、艺术字倒角高光与背景受光方向必须一致；背光面统一压暗至同一环境底色。
2. **环境色互染与边界消融**：
   - 角色不能保留与背景毫无关系的纯白底或死硬切边。用背景的主色调给角色暗部和边缘加上柔和的环境反射光（Ambient bounce light）或轮廓逆光（Rim light）。
   - 角色站立处、坐靠处、道具摆放处、UI 底板贴合处必须画出清晰的**接触阴影（Contact shadow）与环境遮蔽（AO）**，或用前景烟雾、草木、光带、衣摆自然压住交界线。
3. **前—中—后景明度与清晰度阶梯**：
   - **前景**（占 5%–15%）：压暗或微虚的飘落物、武器一角、光斑，拉出镜头距离。
   - **中景主体**（核心焦点）：最高明度反差、最锐利边缘、最丰富色彩。
   - **远景/背景**：主动降低对比度、概括琐碎纹理，在主体头肩周围和标题背后形成平稳的衬托色块。
4. **标题与信息面板的承托融合**：
   - 标题绝不直接裸贴在杂乱的高反差背景纹理上。通过**场景自然暗部（渐暗夜空、阴影墙面、墨迹晕染）、柔和局部压暗光晕、或从题材提炼的定制切角底板/卷轴/金属牌**来承托文字，使字组成为画面空间的一层。

## 四、疏密分区、防拥挤与内容完整性保护

1. **三区面积与对比度分配**：
   - **精细区（约 20%–30%）**：主角脸、眼神、标志性武器/核心奖励、主标题。集中 80% 的锐利高光与精细笔触。
   - **支撑区（约 40%–50%）**：次要角色、服装大形、场景主体建筑、模块边框。使用中等对比度与概括块面。
   - **安静区（不少于 25%–30%）**：正文阅读区、按钮周围、主体轮廓外侧。严禁在此区域生成高频碎光、密集网格、杂乱碎石或高反差背景图案。
2. **内容多时的铁律——“保内容、砍噪音、做收纳”**：
   - **绝不删减用户要求的内容**：用户指定了 4 个角色、5 项活动福利或 3 段介绍文案，必须全部完整呈现。
   - **用结构收纳代替散乱堆砌**：将多项奖励或多段文案收进对齐的卡片网格、标签条或统一的章节底板内，统一字号层级与间距。
   - **砍除重复职责的装饰**：如果画面已经有角色技能特效，就不要再加满屏飞石、多重复杂花边、背景大法阵和强噪点颗粒。每增加一种装饰，必须问自己“它是在帮主体聚焦，还是在和主体抢戏”。

## 五、构图草稿与版式蓝图标准（H5长图 / 多模块方案）

制作构图草稿时，草稿不是敷衍的线框，而是**可视化设计提案 + AI 生图的空间控制图**：

1. **模块节奏与结构可见**：首屏主视觉、过场衔接、核心内容块、底部落版要有明显的高度差与版式变化（如首屏大图破框 → 第二屏左文右图错落卡片 → 第三屏居中网格展示），禁止从头到尾排成一模一样的“居中标题+矩形空框”。
2. **文案完整且绝不越界**：
   - 填入真实完整的标题与正文文案，字号层级分明（主标题 > 章节标题 > 正文 > 注释）。
   - **严格核算文本框宽高与内边距**：文字距离底板四边留出充足呼吸空间，**严禁文字超出底板边界、压在边框线上、跨章节溢出或盖住角色脸部**。
3. **素材落位与视觉朝向合理**：
   - 已获准复用的角色/道具图按构图合理放置（注意角色的视线和动作朝向画面内侧或核心信息区，不面朝画布外边缘）。
   - 待生成的艺术字槽位（Slot）尺寸与实际字组长宽比匹配，不把横排四字标题塞进极扁或极窄的怪异框里。
4. **画面干净无工程噪音**：草稿画布内部不写“1080×1400”“此处放AI背景”“普通字体占位”等给程序员看的说明字样。

## 六、成对教学案例（弱方案 vs 专业改进方案）

### 案例 A：单角色主题 KV 与定制艺术字组
- **条件**：蓝白金配色角色，配有圆环法器，允许新动作；标题“星环回响”，无其他副标要求。
- **弱方案（套路/拼贴）**：人物正面居中站桩，背后贴一个通用发光法阵，底部放一排等大的金色立体黑体字，四周洒满碎星点，并擅自加上“角色视觉设计 / STAR RING”小字。
- **专业改进**：以圆环法器为构图斜向支点，角色侧身回眸、衣袂随星轨舒展（清透幻想赛璐璐+商业KV级精细度）；标题“星环回响”采用修长高对比切面衬线字组，“星”“响”略大、首字延伸一道纤细金弧托住后字，冷白晶石字面配窄暖金倒角，不加多余假副标；背景用深邃靛蓝夜空暗部自然承托脸与标题。

### 案例 B：有外部风格参考图时的边界控制与缺失素材规划
- **条件**：用户提供我方古风女剑客立绘（图1），并提供一张其他游戏的暗黑哥特风海报（图2，内含古堡、十字架、荆棘玫瑰边框与哥特金属字），要求“参考图2的暗调压迫感与构图节奏，做一张新版本海报”。
- **弱方案（违规挪用）**：把图1角色放进去，背景直接画上与图2相似的哥特古堡和十字架，标题四周套上图2同款荆棘玫瑰金框（只把玫瑰改成了红色）。
- **专业改进**：
  - **参考拆解**：只借图2的“70%低明度暗部 + 右上侧逆光冷暖对冲 + 左下角紧凑字组”的构图与光影方法；**严禁出现古堡、十字架、玫瑰荆棘**。
  - **缺失素材规划**：结合图1女剑客的“墨竹与寒铁长剑”设定，自主规划新背景为“暴雨夜的竹林残碑暗影”，规划标题字组为“苍劲刀笔行书配寒铁切口与竹叶飞白”，实现画风神似而具体元素 100% 原创贴题。

### 案例 C：多信息运营弹窗 / H5 章节（防拥挤与保完整）
- **条件**：展示主推角色、3 项活动规则文案、4 个档位奖励图标及行动按钮。
- **弱方案（拥挤/删减）**：要么为了好看删掉两段规则文案，要么把角色、4个大发光宝箱、3段大字和华丽雕花边框全塞成同等大小，文字贴死边框甚至溢出。
- **专业改进**：角色占左侧视觉重心并微破上框，视线引向右侧；右侧用一块低对比深色切角底板（安静区）整齐收纳 3 段规则文案（留足行距与内边距）；4 个奖励按“1个主奖励放大 + 3个次奖励等大对齐”排列在下部；全图只保留角色与主奖励处的高光，底板边框简化为干净的单层细金线。
