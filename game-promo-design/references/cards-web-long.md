# 网页、版本专题与 H5 长图

带主标题或参考图的长图任务，按需同读[字组设计](craft-typography.md)与[参考图用法](reference-usage.md)。静态 H5 先定布局与素材清单，制作和裁切所需素材，再融合成一张完整页面。

## 1. H5 活动长图 / 角色宣传长图
- **成功标准**：手机竖屏滑动时视觉节奏起伏清晰（首屏镇场 → 章节递进 → 尾屏收束），一屏一个核心重点，人物、背景、标题字组与章节信息融为一体，无生硬分段拼接感。
  - **构图草稿阶段标准（生图前必达标）**：
  - **真实布局与有依据的占位**：草稿摆好已有首图与素材、准确文案和阅读动线；缺失但计划制作的部件允许用形状代替。每套方案登记素材清单，说明形状将被什么替换、哪些区域由连续背景承托、需生成多少AI图及裁出多少素材；不用普通文字和空框冒充已完成设计。章节高度随内容量安排，模块可以是全出血插画、开口承托、局部材质或无框图文，不默认每章一个矩形卡。
  - **严格的三级字号层级与纯洁文案**：填入面向玩家的准确章节标题与正文（**严禁将“背景创意提案”“视觉主题提炼，非技能机制”“普通字形占位”等内部沟通解释写进画面文案**）；草稿内首屏主标题（`56–72px`）必须明显大于后续章节小标题（严格限制在 `36–44px`），正文 `28–34px`，辅助说明 `≥24–26px`；**严格控制文本框宽高与内边距，绝不允许文字越出底板框、压线或遮挡角色脸部**。
  - **大标题预留区**：主艺术字及必要的辅助短句共用一个合理比例的透明标题槽（Slot）；在版式说明与制作指令中写清量化的大小字比例与方位、1处集中母题及平面字反浮雕/反金边约束。
- **整页与成品视觉融合标准**：
  - **草稿与正式素材分工**：布局样图只定结构，不默认作为最终生图参考。艺术大标题独立透明制作，小标题、模块样式与附属元素按同类成组后裁切；在模型参考上限内整理正式素材组。最终prompt说明每个部件的模块归属，不把整张素材组、占位形状或草稿字体复制进成品。连续背景与过渡由整页设计完成，首图已有则复用，缺少才补做。
  - **整页精准画风 + 质量词**：在完整页面的 `prompt` 开头写明从 14 类细分艺术画风中选定的名称、五维画法描述与配套质量增强词。受画幅或工具限制需要分段制作时，各段共享画法、光源和色调，合成后检查接缝。
  - **首屏（Hero Section）**：KV 级构图张力，角色（彻底消融原图灰底）与独立透明大标题字组形成明确的第一、第二焦点，主光源方向一致。
  - **中段与尾屏（章节标题强制降级 + 装饰收束）**：后续章节标题在 Prompt 中必须写为“简洁克制的次级章节小标题（宽度不超过画幅 40%，纯色字面配细线或轻量底条，无大型羽翼、无繁复金框与浮雕）”，**绝不让章节标题与首屏主标题抢戏**；外围羽毛、晶石、光流仅点缀在边缘转场处（≤15% 面积），不铺满全页；正文与底部说明字号饱满清晰，确保手机端一屏内无需放大即可直读。
- **雷区**：每屏都是千篇一律的“居中标题+矩形空框”；直接把参考图里的道具/边花改色搬进长图；大标题像普通黑体加发光描边；生成整页后在大标题底下又重复画一行相同小字。

## 2. 版本专题长页（Version Special Page）
- **成功标准**：承载大版本更新全量信息（首屏版本 KV + 新角色立绘与技能切页 + 新活动/新地图展示 + 版本福利汇总），模块清晰且全页共享同一套世界观视觉母题。
- **做法**：确立全页统一的“视觉母题组件”（如统一的章节序号徽标、统一的边框切角或阵营纹章、统一的主辅色调）；角色展示区突出大立绘剪影与性格台词，福利汇总区采用高辨识度的网格或主次奖励台排列。

## 3. 官网首屏大图（Official Site Hero）
- **成功标准**：打开瞬间建立顶级世界观沉浸感，同时为顶部导航栏、中间或偏下方的“立即下载 / 立即预约 / 观看PV”核心按钮留出稳定高对比承载区。
- **做法**：16:9 或超宽画幅；主体与主标题字组避开顶栏 80px 与四角 UI 挂载区；按钮周围预留暗部或净空，保证 UI 叠加后不抢焦。

## 4. 买量转化落地页（UA Landing Page）
- **成功标准**：承接广告点击，1 秒内印证广告卖点并促成点击下载。
- **做法**：首屏延续投放素材的核心视觉钩子与大号利益点标题，下载 CTA 按钮置于首屏拇指热区且高对比醒目；下方精简为 2–3 屏高冲击卖点图卡。

## 5. 商品 / 皮肤 / 典藏礼盒详情长图
- **做法**：按“主视觉全景 → 角色/外观三视图与材质特写 → 局内技能特效/动作展示 → 附赠头像框/徽章/周边一览 → 获取方式说明”从上到下编排，特写框与主背景色调统一。
