# 游戏内素材

游戏内素材要**和游戏实际画面放在一起时成立**：风格统一、尺寸可读、能批量做成一套。原生透明素材再读 [透明素材质量](transparent-assets.md)，将选定画法与相关质量要求写进实际 `prompt`；不要用“高清、精致、无瑕疵”代替可观察的标准。

## 技能图标
- **成功标准**：小尺寸下一眼区分不同技能，并能看出技能的属性和效果。
- **做法**：一个图标一个核心形象（火球、剑气、护盾、治疗之光），占满图标；用颜色区分属性（火红、冰蓝、毒绿、圣金），用形状区分类型（攻击尖锐、防御圆厚、辅助柔和）；强对比、发光边缘。同一套图标统一视角、光照方向、边框和背景处理。
- **雷区**：细节过多缩小后成一团；整套风格不统一。

## 道具图标
- **成功标准**：一眼认出是什么物品和稀有度。
- **做法**：物品居中、略带角度（常见 3/4 视角）显示体积，整套统一光源。稀有度按项目已有配色与形制表达；只有需要图标底板时才画底板，独立透明道具不擅自加底板、场景或承托地面。画法要具体，例如手绘道具可用有粗细变化的深色轮廓、概括明暗面和少量局部笔触；金属用窄亮边与较硬反射区，宝石用清楚的大切面与内部色阶，布料用柔和折面，不能统一糊成塑料高光。
- **质量重点**：轮廓完整，零件连接与透视成立，尖端不被画幅切断；小尺寸仍分得清主形和附属件。透明外底干净，真实孔洞连通，细链/细柄连续，限制无目的的碎屑和大面积光雾。具体风格以用户素材为准，不把手绘例子套到像素或写实资产上。
- **雷区**：背景与物品抢；同套道具视角和比例不一；用“更多雕花和更强发光”冒充质量提升。

## 头像框
- **做法**：先确定头像显示区与装饰范围，中心是真正的透明开口，框外也透明；装饰沿边缘组织，不遮挡面部。开口比例由头像形状和实际使用尺寸决定，不套用固定百分比。具体说明轮廓粗细、转角、框体厚度、上色方式及不同材质的反光。
- **质量重点**：内外两圈边缘都干净，框体连接完整、宽窄变化有意图；内孔不残留底板、假玻璃、灰雾或人物。保留有意的描边与局部辉光，不能出现多余色边；系列等级用轮廓和重点装饰区分，不必层层堆碎细节。

## 成就徽章
- **做法**：清晰的剪影和中心符号优先，系列统一造型与材质语言，再用等级变化表达稀有度。实心徽章保留中心底板；除非用户要求镂空，不沿用头像框挖空中心的规则。

## 卡面
- **成功标准**：卡牌列表里有收藏感，稀有卡一看就珍贵。
- **做法**：角色有张力的瞬间，构图要考虑卡框遮挡区域（名字、数值栏位置）；稀有度通过背景特效、光效强度和画面复杂度体现。

## 立绘
- **成功标准**：角色设计信息完整清楚，同时有性格和姿态魅力。
- **做法**：全身或大半身，姿势展现角色性格和武器；服装结构、配色、材质交代清楚；背景通常简洁或透明，便于游戏内使用。
- **透明立绘质量**：实体内部保持不透明，肢体、发束、羽翼与装备结构连贯，发梢、飘带和羽毛间的空隙分清；硬质装备边缘清楚，柔软边缘有自然过渡，不把所有边缘锐化成剪纸。允许重画时保留已指定的身份与画法；明确原图不重画时转原图去底，不以新立绘代替。

## 角色设定 / 三视图
- **做法**：正、侧、背视图比例一致、对齐；配表情差分、武器和配饰细节特写；用于制作参考时清晰优先于氛围。

## 场景原画
- **成功标准**：交代空间结构、氛围和世界观。
- **做法**：明确的视角和透视，光照营造情绪；为玩家可活动区域留出可读的空间。

## UI 面板与按钮
- **成功标准**：在游戏里可用：层级清楚、可点击区域明显、与游戏美术统一。
- **做法**：面板、标签、按钮、图标位按功能排出层级；主按钮醒目，次按钮弱化；材质和装饰语言来自游戏世界观（魔幻用金属雕花，科幻用光线面板）；同一套 UI 统一圆角、描边和配色。

## 登录 / 加载背景
- **做法**：横版或竖版大图，世界观氛围优先；预留 Logo、进度条和提示文字的区域（通常在下方或一侧），这些区域画面要相对平静。

## 抽卡出金展示立绘 / 觉醒立绘（Gacha Splash Art）
- **成功标准**：抽中最高稀有度角色时的巅峰情绪回馈，角色与专属背景特效、伴生造物融为一幅完整大作。
- **做法**：极具张力的透视镜头与大动态姿势，围绕角色元素属性构建环绕式前中后景特效与专属场景物件，主光源聚焦面部与核心武器，预留左下或右下角色名与星级展示净空。

## 称号牌 / 个人名片背景 / 卡背與命座图腾
- **称号牌与个人名片背景（Nameplate & Profile Banner）**：超宽条形画幅，一侧凝练呈现角色剪影或主题徽记，主区域保持平缓渐变的安静暗部/雅致底纹，确保叠加玩家昵称、签名与头像后清晰可读。
- **卡牌卡背（Card Back）与命座/天赋图腾**：严格的中心对称或旋转对称构图，外框倒角精致，中心镶嵌高辨识度能量核心或星象线条，缩放至小尺寸仍层次分明。

## 游戏内资产 · 稀有度视觉分级体系（Rarity Tier Matrix）

成套制作道具框、卡面边框、徽章、段位图标或礼包底板时，必须按以下 **4 个可观察维度** 建立清晰的等级递进，避免“低阶和高阶长得差不多”或“靠无脑堆碎刺充当高稀有度”：

| 等级档位 | 常见代表色系 | 外框几何轮廓复杂度 | 材质与高光对比 | 核心能量与背光层次 |
|---|---|---|---|---|
| **基础级（N / 绿 / 灰白）** | 哑光铁灰、质朴木棕、森林暗绿 | 单层基础几何形（标准方框、圆环、素盾），四角仅做简单小倒角，无外延尖刺 | 哑光生铁、粗麻、原木或素陶质感；漫反射为主，无锐利镜面高光 | 无发光或仅有极微弱的环境暗角，底板平整安静 |
| **进阶级（R / 蓝 / 青）** | 冷钢蓝、秘银白、青铜色 | 双层嵌套轮廓，四角加入利落的几何切面或简练金属包角，轮廓仍在标准边界内 | 抛光精钢、平滑青铜或单切面蓝晶；受光棱边有一道干净的冷白窄高光 | 内框边缘带一圈极细的微弱冷蓝导光槽，无外溢粒子 |
| **稀有级（SR / 紫 / 暗金）** | 皇家深紫、暗金、幽青紫 | 外轮廓局部破框：顶部或两侧生长出成对的羽翼、卷角、符文护翼或菱形晶簇，形成明确方向感 | 锻造鎏金嵌紫晶/珐琅釉面；金属窄亮边与深色反射区反差强烈，晶石内部有色阶过渡 | 核心晶体或内框散发柔和的紫色/青金局部辉光，伴随 3–5 颗有序漂浮的微粒 |
| **传世/至臻级（SSR / UR / 炽金 / 幻彩）** | 曜石黑配炽亮黄金、星穹幻彩、赤红熔金 | 多层次主次咬合结构：顶部主冠冕/神圣光环 + 两侧舒展护翼 + 底部收束铭牌基座，外轮廓剪影极具统治力 | 复合高级材质（如拉丝黄金+通透星辉钻石切面+半透明流光绸带）；切面高光清脆夺目，层次分明 | 中心具备明确的主光源爆发感与环绕流光轨迹（若为透明头像框，流光严格留在外圈且自然衰减至完全透明，绝不侵入中心内孔） |
