# 多角色站位与调度

角色多时，先决定“谁是主角、他们在一起做什么事”，再选站位。下面的站位是常用选择，不是固定公式；位置用“画面左/右”，角色自身的左右另行说明。

## 先回答三个问题

1. **主次**：谁是这次宣传的主角？其他角色是支撑、对手还是同伴？主次来自传播目标，不按身高、性别或上传顺序决定。
2. **事件**：他们在一起做什么？出发、对决、守护、庆祝、集结……同一件事把角色连在一起，避免各自摆拍。
3. **视线**：观众先看谁、再看谁？用视线方向、动作线和光把目光依次引过去。

## 常用站位

### 两人：对峙
- 两人分站画面左右，面向彼此，中间留出冲突空间（武器交锋点、能量碰撞）。
- 主角离镜头更近、更大、更亮；对手稍远或被逆光压暗。
- 适合：对决、宿敌、阵营对抗。

### 两人：并肩
- 两人一前一后或一高一低，朝向同一方向（远方的目标或敌人）。
- 前面的人是主角，后面的人身体部分被遮挡，但脸和标志性配件完整露出。
- 适合：搭档、恋人、师徒、同伴出发。

### 三人：三角形
- 主角在前方中间或偏一侧，两个支撑角色在后方两侧，形成稳定的三角。
- 三人的高度和远近要有差异，不能排成一条直线。
- 适合：版本主角团、小队。

### 四到六人：前后分层
- 第一层：主角一人（最大、最清楚）；第二层：两到三个重要角色；第三层：其余角色较小或部分可见。
- 每层的角色朝向和动作不同，但都指向同一个事件或方向。
- 适合：版本阵容、阵营群像。

### 六人以上：纵深或环形
- 纵深：沿一条斜线由近到远排开，近大远小，用景深控制清晰度。
- 环形：围绕一个中心（宝物、旗帜、Boss）站成一圈，所有人朝向中心。
- 只让主角和最多两三个角色完整清晰，其他人用剪影、背影或部分可见来减少信息量。

## 遮挡与动作规则

- 脸、手、标志性武器和配件不能被别人挡住，也不能被画面边缘裁掉（除非有意裁切）。
- 两个角色的武器、头发、轮廓不要“贴边”（刚好挨在一起），要么明确重叠、要么分开。
- 动作要符合角色的服装、武器和能力：拿大剑的角色不做轻盈的芭蕾动作。
- 保留身份不等于照搬设定图的站姿，动作可以为本次事件重新设计。

## 写进提示词的方式

按“角色 — 位置 — 大小 — 动作 — 视线 — 遮挡”逐个写，每个角色的服装和武器紧挨着该角色写，避免属性串到别人身上。

示例：画面右侧前景是图1的女剑士，占画面高度约三分之二，右手持剑斜指左下方，视线看向画面左侧的敌人；画面左侧中景是图2的男弓手，身体约为女剑士的一半大，拉弓朝向同一个敌人，他的左肩被女剑士的披风部分遮挡，但脸和弓完整露出。

## 自检

缩小后能一眼认出主角吗？角色之间是否在做同一件事？每个角色的脸和标志物是否都完整可见？
